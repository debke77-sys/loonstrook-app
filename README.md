# Loonstrook

Web-app voor op het beginscherm van je iPhone: prikklok, loonstrookcontrole (CAO Gehandicaptenzorg, ORT) en uitleg in gewone taal.

- Er staan hier geen persoonlijke gegevens. Uren en loonstroken blijven op je eigen telefoon.
- Installeren: open de GitHub Pages-link in Safari, tik op de deelknop en kies **Zet op beginscherm**.
